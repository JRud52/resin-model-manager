        Map folders

        Say what each folder in this path is. Folders above the release are the creator or skipped; folders below the model (supported, heads, ...) are read automatically.

        The mapping is used for every file in that folder with the same layout, so mapping one release of a creator fixes all of them. A mapping on a deeper folder wins over a wider one.

        Corrections

        Each rule applies to every file whose path starts with the folder shown. Delete a rule to go back to the automatic guess.

        Folder mappings

        Each mapping says which folder levels are the creator, release and model for every file in the folder shown. Use Map folders on a model to add one.

        Settings

        Comma separated. A top-level folder with one of these names is skipped when reading creators: inside it, a folder named after a known creator is the creator, anything else is a release.

        The model window shows only your preferred format and version, with buttons to switch to the others. Models that don't have it show what they do have.
